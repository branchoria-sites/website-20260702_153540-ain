## Why Isère has a distinctive UFO record

Isère is a mixed terrain department: Grenoble and its suburbs, the Bièvre plain, the Vercors and Belledonne ranges, ski resorts, valleys, rural plateaux and active aviation corridors all sit close together. That matters because many UFO reports begin as honest attempts to interpret unfamiliar lights seen against mountains, clouds, ridgelines or night skies. A bright object partly hidden by a ridge, a balloon moving through wind shear, a ski-resort vehicle illuminating cloud, or a meteor crossing low on the horizon can look far stranger in the Alps than it would in a flat open landscape.

The department also has aviation context. Grenoble Alpes Isère Airport is at Saint-Étienne-de-Saint-Geoirs, around 40 kilometres from Grenoble, and the airport site hosts light and recreational aviation activity as well as seasonal passenger traffic.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.grenoble-airport.com/en" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: grenoble-airport.com">[Grenoble Airport]</a><span class="citation-popover" role="note"><span class="citation-popover-source">grenoble-airport.com</span><span class="citation-popover-snippet">Open source on grenoble-airport.com.</span></span></span> That does not mean Isère UFO cases are “really aircraft” by default. It means any serious investigation has to check aircraft, helicopters, balloons, satellite passes, meteor events, local wind and mountain visibility before treating a case as anomalous.

GEIPAN’s own Isère catalogue shows this ordinary-but-important pattern. Recent cases include Échirolles in 2024, classed as a probable cluster of balloons; Maubec in 2023, classed as a probable meteor; Cessieu in 2023, explained as Mylar-type balloons; and Eybens in 2022, explained as reflections from snow-grooming vehicle lights on cloud above the Belledonne/Alpe d’Huez sector.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2024-07-51591?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_departement_target_id=Is%C3%A8re+%28216%29&amp;field_document_existe_ou_pas_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;select-category-export=nothing" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span> For a reader, the lesson is not that witnesses are foolish. It is that Isère’s geography gives ordinary lights unusually good opportunities to look unfamiliar.

## The Saint-Geoirs 1976 case: close, strange, but thinly evidenced

The most historically striking Isère case in the GEIPAN record is Saint-Geoirs, observed on 25 November 1976 at about 7.10 am. According to GEIPAN’s summary, a farmer out hunting first saw a red glow he thought might be a chimney fire. He then reported a scintillating light moving east to west, coming within roughly 10 to 15 metres, where he perceived an elongated cylindrical object about two metres long. The object was said to hover about 10 metres above the ground, with an intermittent red glow around it, then move silently south, pause, move again and disappear behind the landscape.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1976-11-02763" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This is exactly the kind of case that draws public attention: close range, apparent object structure, low altitude, silence and a change of direction. GEIPAN’s file records that a gendarmerie investigation followed, but no other witness was found and no trace was discovered in the indicated passage zone. The agency also notes the difficulty of investigating such an old case retrospectively; it did not retain the aircraft hypothesis, but it still described the case as “poorly consistent” because it rests on one witness and a short observation of about eight to ten seconds.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1976-11-02763" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The important balance is this: Saint-Geoirs is not a debunked case in the official record, but neither is it a strong evidential case in the scientific sense. It remains interesting because the reported behaviour was unusual and because the gendarmerie file entered the official French system. It remains weak because there is no corroborating witness, no image, no instrument record and no trace. GEIPAN’s current framing, a D/D1-style unexplained case with high strangeness but limited consistency, is a careful middle position rather than a dramatic claim.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1976-11-02763" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span><img src="{{"/assets/images/Isere_7db861-Illustration-1-dark.svg" | relative_url }}" alt="What Makes Isere&#x27;s UFO Record So Awkward? illustration 1" data-theme-src-dark="{{"/assets/images/Isere_7db861-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{"/assets/images/Isere_7db861-Illustration-1-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">
## Montchaboud 2012: a modern unresolved case with better testimony, not better proof

Montchaboud, observed on 26 July 2012 at about 10.20 pm, is the other key Isère case. GEIPAN describes a witness on a balcony seeing a fast, silent, faintly luminous “vaporous” ball cross a clear sky from south to north, with small luminous points beneath it and several short trailing jets behind it. The observation lasted about six seconds before the object was hidden by the roof of a house.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2012-07-08299" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The case is significant because it is more recent, more carefully documented by the witness, and explicitly classified D1 by GEIPAN. The agency gave it a consistency score of 0.75 and an strangeness score of 0.60, but still emphasised that it was a single-witness case without photo or video. GEIPAN considered several possible [explanations]({{'explanations-dff4bc/' | relative_url }}) and found that none fitted well enough to close the case.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2012-07-08299" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Montchaboud is therefore stronger than many casual light-in-the-sky reports, but it is not a “smoking gun”. Its value lies in showing what GEIPAN means by a serious unresolved file: the witness account is detailed, immediate and structured; common explanations were considered; yet the evidence remains too limited to identify the phenomenon. The weakest point is obvious. A six-second view, from one location, with no independent observation, cannot support a confident extraordinary conclusion even when the witness is careful.

## The larger Isère pattern: many mysteries shrink under investigation

Most of the department’s public record becomes more understandable when cases are grouped by explanation type rather than treated as isolated wonders. GEIPAN’s Isère list includes many A, B and C classifications as well as the unresolved cases. A means the phenomenon is identified; B means the explanation is probable; C usually means there is not enough reliable information to decide; D/D1 indicates an unresolved case after investigation. GEIPAN says its classification method is based mainly on residual strangeness after investigation and the consistency of the information gathered.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/actualites/methodologie-classification-geipan" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">methodologie classification geipan</span><span class="citation-popover-snippet">methodologie classification geipan</span></span></span>

Several recurring explanations stand out in Isère:

**Balloons and balloon clusters.** The Échirolles 2024 case involved two witnesses and a short video of a silent white luminous object moving slowly and regularly. GEIPAN studied aircraft and balloon hypotheses, rejected the aircraft explanation largely because no matching aircraft appeared on radar data, and judged a cluster of balloons more plausible based on shape, movement, wind and video measurements.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2024-07-51591?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_departement_target_id=Is%C3%A8re+%28216%29&amp;field_document_existe_ou_pas_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;select-category-export=nothing" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span> Cessieu 2023 was even clearer: daytime groups of bright spheres appeared, disappeared and moved slowly; GEIPAN concluded they were likely Mylar-type balloons reflecting sunlight and turning in the wind.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2023-07-51454?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_departement_target_id=Is%C3%A8re+%28216%29&amp;field_document_existe_ou_pas_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;select-category-export=nothing" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

**Lanterns.** Saint-Clair-du-Rhône in 2022 produced a red-orange point with a halo, silence and apparently odd movements. GEIPAN classed it as a probable sky lantern, noting colour, halo, low wind, party timing and local heat effects that could explain short vertical changes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2022-05-51392" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span> Eybens 2023 likewise involved orange lights above the Vercors, with GEIPAN judging two sky lanterns the most likely explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2023-01-51415" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

**Mountain and weather effects.** The Eybens 2022 report is especially useful for Isère because it ties the UFO problem directly to Alpine terrain. Three witnesses saw a bright arc above the Belledonne ridges and at first thought it was the Moon, then realised the Moon was elsewhere. GEIPAN investigated and concluded the likely cause was the reflection of powerful snow-grooming vehicle lights on cloud in the Alpe d’Huez/Pic Blanc area, roughly 30 kilometres away.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2022-02-51307" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

**Rare natural lights.** La Mure, originally more puzzling, was revisited and reclassified as probably a transient storm-related luminous phenomenon. GEIPAN noted two independent witnesses and rapid luminous movements near Mont Cimon, but concluded that a rare luminous electrical phenomenon matched the reported appearance, persistence, possible repetition over several days and local environmental conditions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1978-11-00569" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

These cases are not boring footnotes. They are the substance of Isère UFO history. They show how reports can be sincerely strange at first sight and still become explainable once investigators reconstruct direction, weather, terrain, timing, light sources and witness position.<img src="{{"/assets/images/Isere_7db861-Illustration-2-dark.svg" | relative_url }}" alt="What Makes Isere&#x27;s UFO Record So Awkward? illustration 2" data-theme-src-dark="{{"/assets/images/Isere_7db861-Illustration-2-dark.svg" | relative_url }}" data-theme-src-light="{{"/assets/images/Isere_7db861-Illustration-2-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">
## Official investigation in Isère: why gendarmerie records matter

France is unusual because it has a long-running official public route for UFO and UAP reporting. CNES says GEIPAN was created in 1977 and works to collect, analyse and archive reports of unidentified aerospace phenomena, with partners including the gendarmerie, police, Air and Space Force, CNRS and Météo-France.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes.fr/en/projects/geipan" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes.fr">[CNES]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes.fr</span><span class="citation-popover-snippet">Open source on cnes.fr.</span></span></span> GEIPAN’s stated method begins with witness collection, file creation, first analysis, investigation and processing, then classification and publication where appropriate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/node/58788" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

## How to read an Isère UFO case without overclaiming

A fair reading of Isère’s record starts with three questions.

First, what exactly was reported? Saint-Geoirs was not just a point of light; it involved a close-range cylindrical object claim. Montchaboud was not just a slow lantern; it was a fast, vaporous luminous ball with trailing features. Those details are why the cases remain interesting.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1976-11-02763" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Second, what independent support exists? In many Isère cases, the answer is limited. Saint-Geoirs had no additional witness and no trace. Montchaboud had a detailed witness statement but no photo, video or second report. By contrast, some explained cases had stronger supporting material: Échirolles and Cessieu included video, while Eybens 2022 benefited from multiple witnesses and a site-oriented investigation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1976-11-02763" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Third, has the explanation improved over time? La Mure is a good example of later analysis weakening the mystery. GEIPAN says the old case was re-examined with newer tools and experience, moving from a more mysterious status to a probable rare luminous electrical phenomenon.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1978-11-00569" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span> Eybens 2022 shows the same principle in a modern setting: what looked like an inexplicable arc above the mountains became intelligible once cloud layers, webcams, grooming vehicles and sightlines were considered.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2022-02-51307" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This approach protects both sides of the subject. It avoids dismissing sincere witnesses too quickly, but it also avoids turning every unresolved file into an extraordinary claim. In Isère, the strongest conclusion is not that the department has a hidden alien history. It is that a small number of reports remain unresolved after official review, while the broader record shows how often unfamiliar lights become understandable when investigated carefully.<img src="{{"/assets/images/Isere_7db861-Illustration-3-dark.svg" | relative_url }}" alt="What Makes Isere&#x27;s UFO Record So Awkward? illustration 3" data-theme-src-dark="{{"/assets/images/Isere_7db861-Illustration-3-dark.svg" | relative_url }}" data-theme-src-light="{{"/assets/images/Isere_7db861-Illustration-3-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">
## What Isère adds to French UFO history

Isère’s place in French UFO history is modest but instructive. It does not have the national fame of Trans-en-Provence, Valensole or other classic French cases. Its value lies in the department-level pattern: rural close encounter claims, Alpine light effects, airport and aviation context, modern balloon and lantern cases, meteor reports, and the filtering role of GEIPAN and the gendarmerie.

The department’s two standout unresolved files, Saint-Geoirs 1976 and Montchaboud 2012, are worth preserving in any serious Isère UFO archive because they remain officially unexplained and contain enough strangeness to resist easy dismissal.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1976-11-02763" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span> Yet they also show the limits of the subject. Neither case has the independent corroboration needed to support a strong extraordinary claim.

The more recent explained cases are just as valuable for public understanding. Échirolles, Cessieu, Saint-Clair-du-Rhône, Eybens and Maubec show how GEIPAN handles modern reports: check the witness account, compare it with wind, terrain, radar or video where available, test ordinary hypotheses, and classify the result.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2024-07-51591?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_departement_target_id=Is%C3%A8re+%28216%29&amp;field_document_existe_ou_pas_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;select-category-export=nothing" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span> For readers, that is the real takeaway from Isère: UFO history is not only a list of mysteries, but a record of how mysteries are made, tested, weakened, sometimes solved, and occasionally left open.

      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
