## Introduction

The main takeaway is cautious but interesting: Eure has genuine unresolved entries in the French public archive, yet many of its most memorable sightings show how ordinary causes can appear extraordinary when seen at night, at low altitude, through cloud, or from a moving vehicle.<img src="{{"/assets/images/Eure_4abf79-overview.webp" | relative_url }}" alt="Overview image for What Really Happened in Eure&#x27;s UFO Files?" loading="eager" decoding="sync" fetchpriority="high">
## Why Eure matters in French UFO records

Eure is not one of France’s most famous UFO departments, but it has three features that make it worth treating separately. First, its public cases stretch back to the early GEIPAN era, including a cluster of late-1970s reports. Secondly, Évreux-Fauville Air Base gives the department a strong aviation context: aircraft, radar, military witnesses and low-level movements matter more here than in a purely rural department. Thirdly, the official record contains a mix of explained, poorly documented and unresolved cases, which makes Eure a good example of how French UFO investigation actually works.

GEIPAN’s method is important because a French “unidentified aerospace phenomenon” is not automatically an alien craft or even a solid object. The agency assesses reports by comparing the perceived strangeness of the sighting with known physical, astronomical, aviation and psychological explanations, while also judging how much reliable information exists. In its scheme, A and B cases are identified or probably identified, C cases lack reliable data, and D cases remain unexplained after investigation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">Geipan Mission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">Geipan Mission &amp; Geipan &#124; GEIPAN</span></span></span>

That distinction changes how Eure should be read. A case classed C is not “mysterious in a strong evidential sense”; it is usually a case where the record is too weak to support either a firm explanation or a firm anomaly. A D case carries more weight, but even then it means “unexplained after available investigation”, not proof of an exotic origin. GEIPAN itself says unexplained cases require strong consistency, while cases can be reclassified if new evidence appears.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">Geipan Mission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">Geipan Mission &amp; Geipan &#124; GEIPAN</span></span></span>

An independent public map built from GEIPAN data counts 38 Eure cases, including 7 class A, 17 class B, 12 class C and 2 class D entries. That count is useful as a reader-facing guide to the pattern, though the primary source for individual case interpretation remains GEIPAN’s own case files.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://carteovni.fr/departement/eure" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: carteovni.fr">[CarteOvni.fr]</a><span class="citation-popover" role="note"><span class="citation-popover-source">carteovni.fr</span><span class="citation-popover-snippet">Open source on carteovni.fr.</span></span></span>

## The two strongest unresolved cases

### Fauville, 23 April 1978: the radar-and-airbase case

The Fauville case is the most technically interesting Eure entry because it combines a visual report from military personnel with a radar indication. On 23 April 1978, after a telephone call, an operational duty officer at Air Base 105 in Évreux observed a red luminous point at roughly 10 to 15 degrees elevation. Personnel at the watch tower also observed the phenomenon as its brightness decreased. A radar then reportedly detected an echo at 20:44 UTC, about 18 nautical miles away, moving towards bearing 330 at an estimated 30 to 40 knots.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1978-04-01879" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This is the sort of detail that makes a case more than a casual “light in the sky” story. The base context matters: the observation came from a military environment, the radar report was part of the file, and GEPAN, GEIPAN’s predecessor, considered and rejected helicopter and balloon explanations. GEIPAN also noted that Venus was very visible that evening in a broadly similar direction, but judged a Venus misidentification very unlikely because the reported position and elevation of the phenomenon differed notably from the planet’s.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1978-04-01879" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The doubts are just as important. GEIPAN notes that the radar trace was weak, was not confirmed by the other radar at Cinq-Mars-la-Pile, and could not be checked against a surviving recording. It also says a false echo, such as a secondary reflection, cannot be ruled out. The case is therefore not a clean instrument-confirmed unknown; it is a moderately strange case with a good witness record but limited hard data. GEIPAN currently lists it as class D and describes it as an unidentified, moderately strange phenomenon.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1978-04-01879" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span><img src="{{"/assets/images/Eure_4abf79-Illustration-1-dark.svg" | relative_url }}" alt="What Really Happened in Eure&#x27;s UFO Files? illustration 1" data-theme-src-dark="{{"/assets/images/Eure_4abf79-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{"/assets/images/Eure_4abf79-Illustration-1-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">
### Lyons-la-Forêt, 19 September 1979: the forest-edge encounter

The other major unresolved Eure case occurred at Lyons-la-Forêt on 19 September 1979. According to GEIPAN’s summary, two witnesses jogging at about 22:00 saw a red glow, shaped like a ball and scintillating like a star. It then appeared to move extremely quickly towards them, made a curve, stopped for three to four seconds roughly 200 metres away above the edge of the forest, and showed a dark mass inside the glow. The witnesses reported no sound, displacement of air or heat.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1979-09-00659" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This case matters because it is not merely a distant point of light. The report includes two witnesses, apparent approach, a short stationary phase, a forest-edge reference point and a description of structure within the glow. GEIPAN’s witness pages also record the setting as forest or semi-natural terrain, a clear night, and a single object-like phenomenon, though one witness described it as spherical while another described an ovoid appearance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/temoignage/2599" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The weaknesses are those of many older close-encounter-style reports: no photograph, no radar, no recovered trace, and a narrative that depends heavily on human perception under unusual night conditions. Still, GEIPAN classifies Lyons-la-Forêt as D, meaning it has not been explained within the available record. In Eure’s department-level history, it is therefore one of the cases most likely to interest readers looking for genuinely unresolved material rather than misidentified aircraft or lanterns.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/en/node/48156" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

## Air Base 105 changes how some Eure sightings read

Évreux-Fauville Air Base is not background colour; it directly affects how Eure cases should be interpreted. The base is in the department and has long been associated with air transport activity. French defence sources describe Base 105 at Évreux-Fauville as a major air force site, and recent official reporting has highlighted its Franco-German C-130J transport role.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.defense.gouv.fr/unites-du-defile-du-14-juillet-2025/14-juillet-2025-troupes-pied/14-juillet-2025-base-aerienne-105-commandant-viot" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: defense.gouv.fr">[Ministère des Armées]</a><span class="citation-popover" role="note"><span class="citation-popover-source">defense.gouv.fr</span><span class="citation-popover-title">14 juillet 2025 base aerienne 105 commandant viot</span><span class="citation-popover-snippet">14 juillet 2025 base aerienne 105 commandant viot</span></span></span>

The clearest example is Conches-en-Ouche in February 2016. Around midnight, several people in cars reported a large, low-altitude object with fixed or flashing coloured lights, moving slowly near the treetops. Four witnesses made statements to the gendarmerie. GEIPAN concluded that the witnesses had seen a C-130 aircraft that had taken off from Air Base 105 at Évreux, flown south-west and passed south of Conches-en-Ouche at low altitude.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2016-02-09429" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The case is valuable because GEIPAN did not simply say “it was an aircraft” and stop. Its explanation discusses why the aircraft looked so strange: a large military transport can seem too big and too slow; witnesses moving in a car can experience a “pivot” illusion that makes a moving object seem stationary; trees can disrupt distance and height judgement; and moonlight or diffusion can create halo-like effects. GEIPAN also noted how witnesses in the same car gave very different distance estimates and different shape descriptions, ranging from circular to triangular.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2016-02-09429" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

For readers, Conches-en-Ouche is a cautionary case. It does not mock the witnesses; on the contrary, it shows how an unfamiliar but real aircraft, seen briefly and emotionally at night, can become a compelling UFO report. It also explains why aviation-linked departments such as Eure need aircraft traffic, base activity and radar checks before any strong conclusion is drawn.

## The late-1970s cluster: not one single “flap”, but a busy archive period

Eure’s older files show several reports within a short period from 1977 to 1979. Louviers on 6 August 1977 involved two witnesses watching a strong yellow-orange light move slowly, stop, show two small red lights, and continue without noise. A week later one witness reported an ovoid luminous object apparently on the ground in a field across a river; no trace or change was found at the supposed landing site. GEIPAN classifies the case C for lack of reliable information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1977-08-00419?order=title&amp;page=95%2C0&amp;sort=desc&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Saint-Sébastien-de-Morsent on 4 November 1977 involved a south-west to north-east passage of a luminous ball. GEIPAN notes that neither the meteorological station nor the radar station at Air Base 105 observed such a phenomenon, though regional press reportedly mentioned two other observers. The case remains C because the information is insufficient.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1977-11-00452" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Les Andelys on 15 November 1977 is more straightforward. Two witnesses saw a fast elongated phenomenon and a luminous trail or burst of sparks. GEIPAN classifies it B and describes the event as probable atmospheric re-entry, with no ground traces found by the gendarmerie.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1977-11-00455" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This short run of cases can look like a local flap if viewed only as a list of dates. The better reading is more restrained: the late 1970s were an active period for French reporting and archiving, and Eure had several reports of luminous night phenomena, but the surviving files vary sharply in quality. The strongest from that period are Fauville and Lyons-la-Forêt; the others are either probably explained or too thinly documented to carry much evidential weight.

## Modern Eure cases often show the value of video and cross-checking

The newer Eure record is dominated less by mystery than by improved documentation. That may sound disappointing, but it is actually useful: photos, videos, weather data and local checks often make it possible to resolve reports that would once have remained doubtful.

At Berville-sur-Mer in June 2019, a witness saw three red-orange luminous phenomena pass silently at intervals of about five minutes and supplied a video link. GEIPAN judged the star Capella and an aircraft to be unlikely, but found the case consistent with sky lanterns: repeated similar lights, colour and shape, flickering on video, gradual disappearance, movement with the wind, and a Saturday summer night context compatible with festivities. The case is classed B, a very probable lantern explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2019-06-50768?field_date_value=2019-08-31&amp;field_is_new_value=1&amp;page=%2C65" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

At Gisors in January 2024, a witness observed successive red lights moving along similar paths and filmed three videos. GEIPAN classed the case A, identifying celestial lanterns, and noted that the videos helped support the analysis even though there was only one witness. The same case illustrates a recurring issue: multiple small lights moving together can be perceived as a larger or more structured object, especially when they appear in repeated formations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/en/node/61005?amp%3Bfield_is_new_value=1&amp;field_date_value=2024-05-28&amp;order=field_date&amp;page=4&amp;sort=asc" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[geipan.fr]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">Open source on geipan.fr.</span></span></span>

At Verneuil d’Avre et d’Iton in March 2023, a witness photographed a dark, sharply triangular, stationary shape above a supermarket car park. GEIPAN classed the case A after local police confirmed it was a kite near the abbey of Saint-Nicolas and supplied a photograph of the kite. This is one of the best examples in Eure of an initially striking shape being resolved through local verification rather than speculation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2023-03-51425" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span><img src="{{"/assets/images/Eure_4abf79-Illustration-2-dark.svg" | relative_url }}" alt="What Really Happened in Eure&#x27;s UFO Files? illustration 2" data-theme-src-dark="{{"/assets/images/Eure_4abf79-Illustration-2-dark.svg" | relative_url }}" data-theme-src-light="{{"/assets/images/Eure_4abf79-Illustration-2-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">
## Weak cases are still useful if they show why evidence breaks down

Not every unexplained-looking case deserves the same attention. Eure has several C cases where the most honest conclusion is that the story cannot be worked reliably.

Bacqueville, 4 January 1994, is a good example. A witness reported a conical, multicoloured luminous phenomenon beneath cloud, later flashes, fear, a distressed dog and bodily sensations. GEIPAN’s re-examination notes that the case had previously been classed D under the name Fleury-sur-Andelle, but was later revised. The agency considered possibilities such as a sky-tracer or aircraft near Rouen airport, but found that key details were missing: no clear duration, angular height, angular size, movement record or observed disappearance. The witness’s strong fear also complicated the reliability of later details. GEIPAN classed the case C, not because nothing happened, but because the record was too weak to validate any explanation or anomaly.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1994-01-01342" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Évreux, 21 November 2018, is similar in evidential terms. A motorist briefly saw a round form with red and green points of light above a field while driving on the RN154. GEIPAN notes misty conditions, a single witness, no photograph, imprecise location and date, and possible confusion with an aircraft or ground vehicle. It also points out that the delay before testimony prevented a radar-trace request. The case is C for lack of reliable information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2018-11-50692" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

These cases matter because they prevent a common mistake: treating every non-explained report as equally mysterious. In Eure, the difference between D and C is central. D cases such as Fauville and Lyons-la-Forêt remain stronger unresolved entries. C cases are better read as incomplete files.

## Common explanations in Eure

The official files show several recurring explanations or near-explanations.

**Military and civil aircraft.** Conches-en-Ouche is the clearest example, where a C-130 from Évreux-Fauville explained a dramatic multi-witness report. Bacqueville also shows how aircraft can remain plausible even when the record is too incomplete to prove the point.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2016-02-09429" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

**Lanterns.** Évreux in 2013, Berville-sur-Mer in 2019 and Gisors in 2024 all involve orange or red silent lights moving in ways GEIPAN considered compatible with sky lanterns. The repeated pattern is important: silent reddish lights, several objects appearing one after another, movement with the wind, and festive-night timing.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2013-05-08456" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

**Astronomical objects.** Saint-André-de-l’Eure in 1989 was probably a bright planet or star seen through high-magnification binoculars, while Gisors in 2013 was judged a probable Moon misidentification: the witness reported a fixed dark-red light, and GEIPAN found the Moon at almost the same azimuth.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/cas/1989-01-01164" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[geipan.fr]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">Open source on geipan.fr.</span></span></span>

## How gendarmerie reports shape the record

The gendarmerie is central to the French UFO archive because many witness accounts enter the system through formal statements. The national gendarmerie explains that reports of unidentified aerospace phenomena can be made to the gendarmerie and should include date, time, duration, location, position in the landscape, shape, size, colour, movement and whether any sound was heard. These details are then written into a formal statement and may be sent to GEIPAN for analysis.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gendarmerie.interieur.gouv.fr/gendinfo/actualites/2022/comment-la-gendarmerie-prend-elle-en-compte-les-etrangetes-dans-le-ciel" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: gendarmerie.interieur.gouv.fr">[Gendarmerie Nationale]</a><span class="citation-popover" role="note"><span class="citation-popover-source">gendarmerie.interieur.gouv.fr</span><span class="citation-popover-snippet">Open source on gouv.fr.</span></span></span>

That procedure is visible in Eure’s files. Conches-en-Ouche included four gendarmerie depositions. Older cases such as Louviers, Les Andelys, Poses and Bacqueville include police or gendarmerie documents in the GEIPAN record. The practical effect is that Eure’s UFO history is not only a set of anecdotes; it is also a paper trail of witness statements, official summaries, re-examinations and classifications.

## What the Eure record really supports

The strongest evidence-supported statement is this: Eure has a documented public record of UFO and UAP reports, including at least two officially unresolved cases, but the record does not support a simple “mystery hotspot” narrative. Its most interesting cases are interesting for different reasons.

Fauville is important because it involves a military-airbase visual observation and a weak radar echo, but the radar evidence is not strong enough to remove doubt. Lyons-la-Forêt is important because it remains a class D two-witness report with an apparent close approach, but it lacks instrumental or physical confirmation. Conches-en-Ouche is important for the opposite reason: it shows how a striking multi-witness case can be resolved when aircraft tracking and geometry are available.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1978-04-01879" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

For a mainstream reader, the department’s UFO history is therefore best understood as a spectrum:<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Unresolved with some weight:** Fauville 1978 and Lyons-la-Forêt 1979.<span class="citation-chip-wrap"><a class="citation-chip" href="https://carteovni.fr/cas/fauville-1978-0401879" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: carteovni.fr">[carteovni.fr]</a><span class="citation-popover" role="note"><span class="citation-popover-source">carteovni.fr</span><span class="citation-popover-title">fauville 1978 0401879</span><span class="citation-popover-snippet">fauville 1978 0401879</span></span></span>
* **Explained or probably explained but instructive:** Conches-en-Ouche 2016, Berville-sur-Mer 2019, Gisors 2024, Verneuil 2023, Poses 2001.
* **Too weak to settle:** Louviers 1977, Bacqueville 1994, Évreux 2018 and similar class C reports.</div>

That spectrum is more useful than either credulity or dismissal. Eure’s archive shows that witnesses can be sincere, frightened and observant while still misreading aircraft, lanterns, the Moon or local objects. It also shows that a small number of cases remain unresolved not because they prove anything extraordinary, but because the available evidence has not yet supported a normal explanation strongly enough.<img src="{{"/assets/images/Eure_4abf79-Illustration-3-dark.svg" | relative_url }}" alt="What Really Happened in Eure&#x27;s UFO Files? illustration 3" data-theme-src-dark="{{"/assets/images/Eure_4abf79-Illustration-3-dark.svg" | relative_url }}" data-theme-src-light="{{"/assets/images/Eure_4abf79-Illustration-3-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">

      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
